# gta-6-tiktok

Images et outils des carrousels TikTok GTA 6 (compte grand_theft_auto_6vi), publiés via Metricool.

- `posts/<date>-<sujet>/` : le `spec.json` de chaque carrousel et ses slides en JPEG.
- `outils/neon.py` : le rendu des slides dans le style néon Vice City.
- `outils/STYLE.md` : les règles de style et de publication.
- `historique.md` : les sujets déjà traités.

Le dépôt est public pour que Metricool puisse récupérer les images. N'y mettre que du contenu destiné à être publié.
