# Banque d'images pour les mèmes

Images de GTA 6 envoyées par Romain : ses propres captures, ou des images qu'il a trouvées ailleurs.
- Nom des fichiers : sujet-court-numero.jpg (ex. jason-lucia-terrasse-01.jpg).
- Crédit : si l'image vient d'un autre créateur, soit une ligne dans credits.txt (« fichier.jpg : Nom du créateur »),
  soit le nom du créateur dans le nom du fichier après deux tirets bas : 20261126-153000__Nom-du-createur.jpg
  (c'est ce que fait le raccourci iPhone « Banque GTA »). Sans « __ », l'image est une capture de Romain.
  Le post ajoute alors « Crédit photo : Nom » à la fin de la description (sans @), et on ne retire jamais sa signature de l'image.
- Une image utilisée est notée dans utilisees.txt pour ne pas la réutiliser.

## Envoi par mail (le plus simple)
Romain partage une image vers son adresse Gmail avec l'objet « Banque GTA » et, dans le message, « Crédit : Nom » (vide si c'est sa capture).
Chaque matin, la tâche récupère ces mails, enregistre les images ici (nom AAAAMMJJ-HHMMSS__Nom.jpg) et note l'identifiant du mail dans mails-traites.txt.
